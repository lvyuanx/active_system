# 活动页面模块说明

## 模块简介

`src/views/activity/` 提供用户端活动入口、活动首页、聊天室和个人页，并由 `index.vue` 承接活动级认证状态与底部导航。

## 主要职责

- 加载活动公开信息和活动用户会话。
- 根据命名路由渲染首页、聊天和“我的”页面。
- 聊天页负责历史消息、WebSocket 实时消息、表情包和发送交互。
- 在移动端处理安全区、软键盘和可视视口变化，保持聊天输入区可用。

## 目录说明

- `index.vue`：活动壳、登录流程、活动会话和底部 Tabbar。
- `chat.vue`、`chat.css`：聊天消息列表、输入区、表情选择器和 WebSocket 生命周期。
- `useKeyboardViewport.ts`：聊天路由的软键盘状态与 `visualViewport` 尺寸监听。
- `home.vue`、`me.vue`：活动首页和当前用户信息页。
- `activity.css`、`activity-auth.css`：活动壳、导航、公共页面和认证页样式。
- `session.ts`：活动壳向子页面提供登出能力的注入契约。

## 核心流程

活动壳加载活动和当前活动用户后渲染子路由。进入聊天路由时，视口组合函数记录未弹键盘时的基准高度并监听输入框焦点、
窗口及 `visualViewport` 事件；可视高度减少超过键盘阈值时隐藏 Tabbar，恢复后显示。输入框聚焦不覆盖基准高度，避免
iOS/WebView 在 `focusin` 与视口变化顺序不同导致状态识别失败；触屏 WebView 缺少视口事件时由焦点延迟兜底。聊天内容
使用可视视口高度、导航高度和安全区变量计算，消息区独立滚动，输入栏保持固定触控按钮尺寸。

## 依赖关系

模块依赖 `api/client.ts` 的活动、聊天和媒体接口，使用 Vue Router、Vue 组合式 API 及 Vant 4 移动端组件。

## 注意事项

- 聊天高度必须继续使用可视视口变量，不能只依赖固定 `100dvh`。
- 键盘显示期间不要恢复 Tabbar 或重复添加底部安全区，否则输入栏会被键盘遮挡。
- 不要在 `focusin` 时重置键盘基准；键盘可能已经在焦点事件前缩小视口。
- 键盘关闭应等待输入失焦或视口恢复，避免键盘动画中间帧提前显示 Tabbar。
- `visualViewport.scale` 变化代表缩放，不应单独触发键盘状态。
- 修改聊天输入区后需要检查 320px 至 430px 宽度下的发送按钮和横向溢出。
