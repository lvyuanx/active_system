# 参与者管理页面说明

## 模块职责

`src/views/participants/` 提供单个活动的参与用户分页列表、模糊搜索、管理员状态操作和移动端抽奖授权入口。

## 主要流程

页面加载活动详情与参与用户第 1 页；管理员可以按用户名或手机号模糊搜索、切换分页和每页条数，并对指定参与用户持久禁言/解除禁言、停用/恢复用户，或授予/取消移动端抽奖权限。
状态操作成功后使用后端返回的完整用户记录更新当前表格，不直接推测状态。

## 目录说明

- `index.vue`：活动参与者页面，负责活动信息、分页搜索、请求状态和状态操作确认。
- `ParticipantTable.vue`：参与者表格展示和行操作事件，不直接访问接口。

## 页面约定

- 参与者管理路由为 `/activities/:activityId/participants`。
- 页面必须复用 `ActivitySidebar`，并将 `active` 设置为 `participants`。
- 停用和禁言操作需要二次确认；恢复和解除禁言直接执行并显示结果反馈。
- 移动端抽奖权限独立于停用和禁言状态保存；授权或取消授权成功后使用后端完整记录更新权限标签。
- 搜索匹配用户名或手机号，搜索和每页条数变化后回到第 1 页；分页状态仅保存在当前页面，不同步 URL。
- 分页列表通过参与者管理接口返回 `items`、`page`、`page_size`、`total` 和 `has_more`，状态操作接口仍返回单个完整参与者记录。
- 本模块不提供密码重置或批量操作。
