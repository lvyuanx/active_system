# 参与者管理页面说明

## 模块职责

`src/views/participants/` 提供单个活动的参与用户列表和管理员状态操作入口。

## 主要流程

页面加载活动详情与参与用户列表；管理员可以对指定参与用户持久禁言/解除禁言，或停用/恢复用户。
状态操作成功后使用后端返回的完整用户记录更新当前表格，不直接推测状态。

## 页面约定

- 参与者管理路由为 `/activities/:activityId/participants`。
- 页面必须复用 `ActivitySidebar`，并将 `active` 设置为 `participants`。
- 停用和禁言操作需要二次确认；恢复和解除禁言直接执行并显示结果反馈。
- 本模块不提供密码重置、批量操作、搜索或分页。
