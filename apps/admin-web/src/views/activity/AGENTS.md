# 管理端活动首页说明

## 模块职责

`src/views/activity/` 提供单个活动的管理首页，展示活动状态、用户端地址、网页二维码、微信小程序码和活动级入口操作。

## 主要流程

页面根据 `/activities/:activityId` 路由加载活动详情，管理员可以复制或打开用户端地址，也可以从“活动入口”面板打开对应活动的公开实时抽奖大屏。
大屏地址由 `src/app-links.ts` 生成，显式 `VITE_SCREEN_WEB_BASE_URL` 优先；生产默认同源 `/screen/`，
开发默认 localhost:5174，并自动附加当前活动的 `activity_id` 查询参数。
微信小程序码通过管理员接口 `/admin/activities/{activity_id}/mini-code` 获取 PNG；接口未配置微信密钥或调用失败时，
页面保留网页二维码并在小程序码面板展示错误状态。小程序码对象 URL 在页面卸载时释放。
桌面宽度下活动入口按地址、微信小程序码、网页二维码三列展示；中等宽度将地址面板独占一行，窄屏恢复单列。

## 交互约定

- “打开抽奖大屏”在新标签页打开 screen-web，不携带管理员凭证。
- 抽奖大屏是公开只读展示；奖项配置和开奖控制继续由侧边栏的“实时抽奖”页面负责。
- 用户端地址和网页二维码显式 `VITE_USER_WEB_BASE_URL` 优先，生产默认同源 `/user/`，开发 localhost:5175；
  微信小程序码由后端生成，不使用 `VITE_USER_WEB_BASE_URL`。
