# 管理端活动选择页说明

## 模块职责

`src/views/home/` 提供管理员登录后的活动列表、状态筛选、活动生命周期操作和创建活动入口。

## 主要流程

页面加载活动列表并按状态筛选展示卡片。点击活动卡片主体进入 `/activities/:activityId` 活动首页；卡片底部的状态按钮负责开启、关闭或结束活动，
“打开抽奖大屏”按钮在新标签页打开配置的 screen-web 地址，并通过 `activity_id` 查询参数定位当前活动。

## 交互约定

- 活动卡片主体保持可点击并支持 Enter 键进入活动首页。
- 卡片 footer 使用点击事件隔离，底部按钮只执行各自操作，不触发卡片主体跳转。
- “打开抽奖大屏”对所有活动状态可用；大屏连接为公开只读连接，实际开奖仍由管理端实时抽奖页控制。

## 依赖关系

页面复用 `src/api/client.ts` 的活动列表、创建和状态变更接口，使用 Vue Router 跳转到活动管理和登录路由；
抽奖大屏地址复用 `src/app-links.ts`，显式 `VITE_SCREEN_WEB_BASE_URL` 优先；生产默认同源 `/screen/`，
开发默认 `http://localhost:5174`，保留配置查询参数并设置活动 ID。
