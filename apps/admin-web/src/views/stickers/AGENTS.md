# 聊天表情包管理页面说明

## 模块职责

`src/views/stickers/` 为超级管理员提供活动级聊天表情包的批量上传、预览、下架和恢复能力。

## 主要流程

页面先加载当前活动和管理员表情列表；文件选择器允许多选，前端按选择顺序逐个调用单文件 multipart 接口，
每项独立展示预览、上传状态和错误。名称默认使用文件名去掉扩展名后的结果。已下架表情仍显示在管理员列表中，
恢复操作只切换启用状态，不删除历史消息引用或媒体文件。

## 依赖关系

- 复用 `ActivitySidebar` 活动管理壳，并使用 `src/api/client.ts` 的表情接口和媒体 URL 解析。
- 后端管理员接口要求超级用户 JWT，图片资源使用公开版本化 URL 预览。

## 注意事项

- 支持 JPG、PNG、WebP、GIF，单文件上限 5 MiB；前端校验只是提示，后端校验才是最终约束。
- 批量上传失败项不能阻断其它文件；移动端只读取当前活动的启用表情。
