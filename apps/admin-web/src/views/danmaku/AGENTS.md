# 弹幕管理页面说明

## 模块职责

该页面面向超级管理员配置单个活动的弹幕投屏器，控制真实聊天室弹幕测试，并复制或重新生成该活动的当前 token。

## 主要流程

页面并行读取活动详情和弹幕设置；保存完整设置后后端会实时通知已运行的投屏器。`DanmakuTestPanel.vue`
读取测试任务状态并提供开启/关闭按钮；启动前可配置至少 1 名测试人员，以及 0 至 60 秒的每条弹幕随机延迟范围，
开启后由后端创建带“弹幕测试用户”标记的活动用户，按真实聊天室持久化和广播链路发送多条消息。重新生成 token
前必须确认，成功后更新页面中的 token 并使旧投屏器断开。

## 注意事项

- 真实弹幕测试为每个测试用户分别启动发送循环；测试人员数量会转化为并发消息来源，不只是轮换展示名称。
- token 仅通过管理员接口读取，不写入浏览器本地存储。
- 弹幕测试不是本地预览；消息会写入当前活动聊天室，仅允许进行中的活动开启。
- 测试配置只在启动请求中生效；测试运行期间表单锁定，最小延迟不能大于最大延迟。
- 文字颜色选择器必须使用 `:show-alpha="false"` 和 `color-format="hex"`，保存请求保持 `#` 加六位十六进制格式。
- 播放设置包含“入场间隔”，范围 0.1–5.0 秒、步长 0.1，默认 1.0 秒；同轨道上一条弹幕完整进入后按此间隔尝试下一条。
- “队列最大等待时间”范围 0.5–5.0 秒、步长 0.1，默认 1.5 秒；仅用于所有轨道暂不可用时的本地队列超时。
- 本地表单先校验显示区域底部大于顶部，后端仍是最终约束来源。
