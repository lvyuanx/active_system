# 管理端共享组件说明

## 模块简介

`src/components/` 保存跨管理端业务页面复用的展示组件。

## 核心组件

- `ActivitySidebar.vue`：活动管理壳层的统一左侧菜单，包含品牌区、返回活动列表、当前活动摘要、
  首页/弹幕工具/参与者导航、暂未开放入口和管理员退出操作。

## 复用方式

活动首页、弹幕工具页和参与者页传入 `activity`、`activityId`、`active` 和 `username`；组件内部统一处理路由跳转
及退出登录，页面不再复制菜单 DOM。菜单视觉规则集中在管理端全局活动壳样式中。

## 注意事项

新增活动管理页面需要优先复用 `ActivitySidebar`，仅通过 `active` 标记当前页面，不要复制左侧菜单结构或
在页面局部重新定义导航样式；返回活动列表按钮与导航项共用扁平按钮基础样式，不使用浏览器默认边框。
