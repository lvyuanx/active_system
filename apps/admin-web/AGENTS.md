# 管理端模块说明

## 生产部署入口

deploy/build.py 通过 Vite CLI 指定 `/admin/` base，Router 使用 `import.meta.env.BASE_URL`。
产物在 deploy/nginx/html/admin，只读挂载至 Nginx；部署打包固定使用同源 API 和应用链接。
API 显式 `VITE_API_BASE_URL` 优先，生产默认同源 `/api/v1`，开发保持 localhost:8000；
WebSocket 先用 URL 解析为绝对地址再转换 ws/wss。`src/app-links.ts` 集中生成活动二维码与大屏链接，
生产默认同源 `/user/`、`/screen/`，显式配置与开发端口仍兼容，活动 ID 与已有查询参数保留。

管理端使用 Vue 3 + Element Plus，负责管理员登录、活动配置、参与者管理、数据查看和系统设置。业务页面放在 `src/views/`，请求封装放在 `src/api/`。

## 当前已实现功能

- `src/views/login/`：超级用户登录页，JWT 保存在浏览器本地存储。
- `src/views/home/`：登录后的活动卡片选择页，提供状态概览、状态筛选、创建、开启、关闭和结束操作，并可从活动卡片直接打开抽奖大屏。
- `src/api/client.ts`：认证令牌、活动接口和统一 401 处理。
- `src/router/index.ts`：登录路由和管理员路由守卫。
- `src/views/activity/`：单个活动管理页，展示活动移动端地址、二维码，并提供打开移动端和抽奖大屏的入口操作。
- `src/views/participants/`：活动参与者列表，以及禁言/解除禁言、停用/恢复操作。
- `src/views/stickers/`：活动级聊天表情包批量上传、预览、下架和恢复。
- `src/views/danmaku/`：活动级弹幕配置、当前 token 复制和 token 轮换页面。
- `src/views/lottery/`：活动级奖项/奖品配置、奖品图片选择/预览/替换/移除、经过安全码验证并按奖品切换的按需分页名单弹窗、管理员 WebSocket 开奖控制、中奖历史和重置页面。
- `VITE_SCREEN_WEB_BASE_URL`：抽奖大屏地址基础 URL，默认 `http://localhost:5174`。
- `VITE_USER_WEB_BASE_URL`：二维码目标用户端地址基础 URL，默认 `http://localhost:5175`。

活动详情请求优先使用单活动接口；为兼容未重启的旧后端进程，接口不可用时会回退到活动列表查询。

弹幕工具页面使用管理员接口读取和保存完整配置；保存后由后端实时推送给弹幕投屏器。每个活动只展示一个当前 token，
重新生成会使旧 token 和已运行连接失效。页面中的真实弹幕测试按钮会控制后端测试任务，测试任务通过真实聊天室
持久化并广播标记为“弹幕测试用户”的消息，不使用本地假预览。

抽奖页面的配置、历史和安全码验证继续使用 HTTP；开奖、错误、重置、配置更新和连接保活使用管理员 WebSocket。
点击“特殊配置”后必须通过后端安全码校验，成功才打开名单弹窗；弹窗先选择奖品，再展示该奖品的参与者总数、可抽奖/黑名单/白名单/已停用统计和规则说明，
主页面只保留入口。连接断开时采用指数退避，未连接时禁用开奖控制；重置前必须二次确认，完整名单仅在验证后的弹窗中按需加载。

奖品图片使用独立 multipart API；本地预览和待保存状态只存在表单内，奖品配置 JSON 保存后再上传/移除图片。
服务端失败时保留原图片并显示错误，不把图片二进制放入配置请求。
保存期间忽略自发配置刷新及其早期异步响应；图片上传或移除失败会恢复待处理状态，允许再次保存重试。

聊天表情包页面使用活动级管理员接口；多文件选择后逐个上传，单项失败不影响其它文件。表情图片使用公开版本化 URL
预览；下架只切换启用状态，历史聊天消息和媒体资源继续保留，恢复后重新进入用户端选择器。

## 视觉结构

管理端采用克制的运营后台风格：活动配置页使用固定左侧导航、右侧独立顶栏和大面积内容画布；活动列表页使用状态统计带、分段筛选和带状态色的卡片网格；登录页与工作台共用品牌标识和语义色。活动首页、弹幕工具页和参与者页共同复用 `src/components/ActivitySidebar.vue`，返回活动列表按钮与菜单项使用统一的扁平按钮基础样式，视觉规则集中在全局活动壳样式中。移动端将配置页导航折叠为顶部菜单，内容面板改为单列。

活动壳桌面端侧栏使用独立的视口高度、顶部粘性定位和自身纵向滚动，不随右侧长内容的网格行高拉伸；宽度不超过 800px 时恢复单列普通流和自然高度。
