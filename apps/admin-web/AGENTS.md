# 管理端模块说明

管理端使用 Vue 3 + Element Plus，负责管理员登录、活动配置、参与者管理、数据查看和系统设置。业务页面放在 `src/views/`，请求封装放在 `src/api/`。

## 当前已实现功能

- `src/views/login/`：超级用户登录页，JWT 保存在浏览器本地存储。
- `src/views/home/`：登录后的活动卡片选择页，提供状态概览、状态筛选，以及创建、开启、关闭和结束操作。
- `src/api/client.ts`：认证令牌、活动接口和统一 401 处理。
- `src/router/index.ts`：登录路由和管理员路由守卫。
- `src/views/activity/`：单个活动管理页，展示活动移动端地址、二维码和基础入口操作。
- `src/views/danmaku/`：活动级弹幕配置、当前 token 复制和 token 轮换页面。
- `VITE_USER_WEB_BASE_URL`：二维码目标用户端地址基础 URL，默认 `http://localhost:5175`。

活动详情请求优先使用单活动接口；为兼容未重启的旧后端进程，接口不可用时会回退到活动列表查询。

弹幕工具页面使用管理员接口读取和保存完整配置；保存后由后端实时推送给弹幕投屏器。每个活动只展示一个当前 token，
重新生成会使旧 token 和已运行连接失效。页面中的真实弹幕测试按钮会控制后端测试任务，测试任务通过真实聊天室
持久化并广播标记为“弹幕测试用户”的消息，不使用本地假预览。

## 视觉结构

管理端采用克制的运营后台风格：活动配置页使用固定左侧导航、右侧独立顶栏和大面积内容画布；活动列表页使用状态统计带、分段筛选和带状态色的卡片网格；登录页与工作台共用品牌标识和语义色。活动首页和弹幕工具页共同复用 `src/components/ActivitySidebar.vue`，返回活动列表按钮与菜单项使用统一的扁平按钮基础样式，视觉规则集中在全局活动壳样式中。移动端将配置页导航折叠为顶部菜单，内容面板改为单列。
