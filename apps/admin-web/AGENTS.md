# 管理端模块说明

管理端使用 Vue 3 + Element Plus，负责管理员登录、活动配置、参与者管理、数据查看和系统设置。业务页面放在 `src/views/`，请求封装放在 `src/api/`。

## 当前已实现功能

- `src/views/login/`：超级用户登录页，JWT 保存在浏览器本地存储。
- `src/views/home/`：登录后的活动卡片选择页，提供状态概览、状态筛选，以及创建、开启、关闭和结束操作。
- `src/api/client.ts`：认证令牌、活动接口和统一 401 处理。
- `src/router/index.ts`：登录路由和管理员路由守卫。

## 视觉结构

管理端采用克制的运营后台风格：统一顶栏承载品牌和账号信息，活动页使用状态统计带、分段筛选和带状态色的卡片网格；登录页与工作台共用品牌标识和语义色。移动端将统计带折为两列，并将卡片操作改为纵向布局。
