# TASK-v2：管理端首页增加抽奖大屏入口

## 任务属性

- 等级：T4
- 状态：已冻结
- 输入版本：TASK-v1 已因用户场景澄清失效，当前工作树存在此前未提交的项目改动
- 变更性质：管理端活动选择页的单模块行为与入口文案调整，不改变后端接口和抽奖协议

## 目标与用户场景

管理员登录管理端首页后，在活动卡片上可以直接打开对应活动的公开实时抽奖大屏，不需要手工拼接 screen-web 地址和活动 ID。

## 范围

- 在 `apps/admin-web/src/views/home/index.vue` 的活动卡片操作区增加“打开抽奖大屏”按钮。
- 使用 `VITE_SCREEN_WEB_BASE_URL`（默认 `http://localhost:5174`）生成大屏地址，并附加当前活动的 `activity_id` 查询参数。
- 在新标签页打开公开大屏；保留既有活动卡片主体和管理端抽奖配置路由。
- 同步首页模块说明、管理端使用文档和项目知识/进度记录。

## 非目标

- 不新增后端接口或页面路由。
- 不改变抽奖配置、开奖控制、活动状态转换和权限逻辑。
- 不修改活动卡片点击进入活动详情的既有行为。

## 约束与风险

- 当前工作树已有此前未提交的抽奖及其它模块改动，不能回退、清理或覆盖无关文件。
- 按钮位于卡片 footer 的事件隔离区域，点击后必须只打开大屏，不能同时触发卡片详情跳转。
- 大屏公开连接只读；管理员仍需进入现有实时抽奖管理页执行开奖。

## 验收标准

### AC-001：活动卡片提供大屏入口

**Given** 管理员已登录首页且存在活动卡片
**When** 查看任一活动卡片操作区
**Then** 可以看到“打开抽奖大屏”按钮，且按钮不依赖活动状态隐藏。

### AC-002：按钮打开对应活动大屏

**Given** 活动卡片的活动 ID 为 `activityId`
**When** 点击“打开抽奖大屏”按钮
**Then** 新标签页打开配置的大屏地址，并带有 `activity_id=activityId` 查询参数，且不会触发卡片主体跳转。

### AC-003：既有行为和构建无回归

**Given** 首页仍使用卡片整体点击和底部状态操作
**When** 执行管理端类型检查与生产构建
**Then** 两项检查通过，卡片点击、开启/关闭/结束操作和现有抽奖管理路由保持不变。
