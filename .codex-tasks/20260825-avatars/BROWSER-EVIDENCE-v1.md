# 用户端头像浏览器核验

任务：T3｜活动用户 SVG 头像与首次登录随机分配

输入版本：TASK-v2

环境：本地 `http://localhost:5175` 的活动入口；已有测试活动 `2a740baa-ea50-497f-9e0a-798fb586d875`；浏览器临时视口在核验后已恢复默认并清理标签。

## 390×844

- 首页 DOM 存在 `img.activity-avatar`，替代文本为“头像预览用户的活动头像”。
- 首页截图确认头像与用户名同一身份卡片展示，底部导航未遮挡。
- “我的”页 DOM 和截图确认展示同一头像，并保留活动用户 ID、加入时间和退出按钮。

## 320×720

- `viewportWidth=320`。
- `scrollWidth=320`，无横向溢出。
- `avatarCount=1`，头像完整展示。
- 首页长用户名在卡片内换行，没有挤出头像容器或活动状态标签。

## 600px 约束

- `activity-auth.css` 在大于 600px 的媒体条件下将 `.activity-page` 限制为 `max-width: 600px` 并居中。
- 活动内容页在 `activity.css` 中对聊天/我的内容限制为 `max-width: 600px`；头像组件自身为固定 72px/52px 圆形尺寸，使用 `object-fit: cover`。

结论：AC-002 的移动端真实页面检查通过；600px 约束由现有 CSS 断点与组件尺寸静态核对通过。十款资源的逐个文件安全/唯一性由 SVG 扫描覆盖。
