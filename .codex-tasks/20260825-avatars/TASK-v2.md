## 任务

T3｜为活动用户交付十款 SVG 头像，并在首次成功进入活动后随机分配一个稳定头像。

## 输入版本

- 产品任务单：TASK-v2
- 输入代码快照：HEAD `bc5ef243f7c8076ff521ac75aa9d4524ec49dcf5`
- 工作树状态：dirty，包含既有聊天室功能改动；本任务不得回滚或覆盖这些改动。

## 目标

交付十款符合用户端炭黑/哑金视觉的纯静态 SVG 几何抽象头像，并为每个活动用户建立稳定、可重复读取的个性化身份头像。

## 用户场景

- 新用户完成当前活动自动注册后，随机获得十款头像中的一款。
- 历史用户在下一次成功登录或有效调用 `/me` 时惰性获得头像。
- 用户再次登录、刷新首页或进入“我的”时，继续看到同一头像。
- 同一用户参与不同活动时，各活动头像可以不同。
- 聊天页面、聊天接口、消息模型和聊天协议保持现状。

## 范围

- 设计并交付恰好十款 SVG 头像。
- 头像采用统一几何抽象风格，沿用炭黑/哑金主题。
- 新用户自动注册成功时随机分配头像，允许不同用户获得相同头像。
- 历史用户在下一次成功登录或 `/me` 读取身份时惰性补齐，不做后台批量迁移。
- 分配结果一旦存在即保持不变。
- 在活动首页和“我的”页展示头像。
- 保留现有活动隔离、登录错误边界和聊天回归要求。

## 非目标

- 不支持用户换头像、上传头像、编辑头像或自定义头像。
- 不做活动内头像均衡、去重或运营配置。
- 不做后台批量迁移。
- 不在聊天页面展示头像。
- 不修改聊天接口、消息模型、WebSocket 协议或聊天身份规则。
- 不建立跨活动共享的全局用户头像身份。

## 约束

- 头像归属必须按 `activity_id + activity_user_id` 隔离。
- 同一用户在不同活动中的头像允许不同。
- SVG 必须纯静态，不包含脚本或外链。
- 用户端继续使用 Vue 3 + Vant 4 和现有移动端视觉规范。
- 适配 320px 起移动宽度、safe-area 和不超过 600px 的桌面预览。
- 不得修改、回滚或覆盖当前未提交聊天功能。

## 验收标准

### AC-001

Given 头像资产进入验收，When 清点并加载头像资源，Then 恰好存在十款可渲染的纯静态 SVG，十款彼此可区分，采用统一几何抽象风格，且不包含脚本或外链。

### AC-002

Given 活动用户已获得头像，When 打开活动首页或“我的”页，Then 两个页面均展示该用户当前活动头像；在 320px 起移动宽度及不超过 600px 的桌面预览中无横向溢出、异常裁切或 safe-area 遮挡。

### AC-003

Given 新用户尚未拥有当前活动头像，When 当前自动注册流程成功完成，Then 系统从十款头像中随机分配一款，并立即可在用户身份信息中读取；分配失败不得导致注册成功但头像为空。

### AC-004

Given 当前活动用户已经拥有头像，When 用户再次登录或成功调用 `/me`，Then 返回并展示与此前相同的头像，不能重新随机或替换。

### AC-005

Given 多名新用户分别完成首次自动注册，When 检查分配结果，Then 每个结果均属于十款头像集合；允许不同用户获得同一头像，不因重复产生冲突、重新分配或均衡调整。

### AC-006

Given 同一用户分别参与活动 A 和活动 B，When 分别读取两项活动身份，Then 两项头像按 `activity_id + activity_user_id` 独立保存和读取，A 的头像变化或读取不得影响 B。

### AC-007

Given 历史活动用户尚无头像，When 该用户下一次成功登录或有效调用 `/me`，Then 仅为当前活动用户惰性补齐一款头像；不执行后台批量迁移，补齐后后续读取结果保持稳定。

### AC-008

Given 用户提交错误凭证、使用失效令牌或使用其他活动令牌，When 登录、注册或 `/me` 请求失败，Then 不创建、不返回不属于当前身份的头像信息，并保持现有认证错误边界。

### AC-009

Given 当前未提交聊天功能作为保护基线，When 完成头像需求后执行聊天回归，Then 聊天路由、稳定 `activity_user_id`、消息模型、历史消息、WebSocket 认证、跨活动隔离和读写状态均保持原有行为。

### AC-010

Given 用户退出当前活动后再次登录，When 重新读取当前活动身份及其他活动身份，Then 当前活动继续使用原头像，其他活动头像保持各自独立，且聊天功能不因退出或重新登录受到影响。

## 风险与依赖

- 既有用户无头像数据，必须由认证成功或 `/me` 成功读取触发惰性补齐。
- SQLite 既有数据库需要以兼容方式新增可空字段，不得批量随机写入历史用户。
- 认证响应被首页、“我的”和聊天相关身份逻辑复用，必须保持稳定 `activity_user_id`。
- SVG 在小尺寸圆形容器中的辨识度和裁切效果需要构建与视觉回归。
