# TASK-v3：管理端弹幕播放设置保存 422 修复

## 任务类型

T2 缺陷修复。任务基线为 `.codex-tasks/20260827-danmaku-desktop/TASK-v2.md`；AC-001～AC-021
保持原义，仅新增 AC-022～AC-023。

## 目标

修复管理员在弹幕工具页面保存播放设置时因颜色值格式不符合既有接口契约而返回 422 的问题。保存有效
播放设置应成功，并保持后端颜色校验与既有弹幕实时同步行为。

## 用户场景

1. 超级管理员进入目标活动的“弹幕工具”页面。
2. 不修改或调整有效播放设置后点击“保存播放设置”，保存成功。
3. 选择新的不透明文字颜色后保存，设置成功持久化并同步到已连接投屏器。
4. 输入非法设置时仍得到明确校验结果，不能通过修改客户端行为绕过后端校验。

## 范围

- 管理端弹幕播放设置页面的颜色选择与保存请求格式。
- 保存成功后的页面反馈、回包回填和已连接弹幕工具同步。
- 增加覆盖默认保存、颜色选择保存和后续读取的回归测试。
- 按仓库规则同步受影响模块说明及测试证据。

## 非目标

- 不改变 PUT 接口路径、响应结构或七个播放设置字段。
- 不放宽后端对颜色、数值范围和显示区域的校验，不接受 `rgb(...)`、`rgba(...)`、颜色名称或八位颜色值作为保存格式。
- 不修改 token、真实弹幕测试、桌面工具、screen-web、聊天室协议及活动生命周期。
- 不处理多副本广播或其他未由本问题引出的功能。

## 约束、风险与依赖

- `text_color` 请求值必须为 `#` 加六位十六进制字符；成功回包及后续读取的颜色为大写十六进制。
- 既有七个播放设置字段的范围和显示区域约束保持不变，所有请求继续绑定目标 `activity_id` 并要求超级管理员权限。
- 必须保留工作树中已有用户改动，不进行无关重构。
- 当前报告未包含 422 响应体；若实际请求含有其他非法字段，测试阶段需区分颜色格式与其他校验问题。
- Element Plus 版本或浏览器缓存可能影响客户端表现，需使用当前构建产物核验请求体。
- 依赖管理端弹幕页面、`src/api/client.ts`、后端弹幕校验以及 Element Plus 2.14.4。

## 已确认事实与待确认项

- 失败请求为 `PUT /api/v1/admin/activities/41f9d161-c015-42d4-a4f5-0cc65ecec285/danmaku`，状态码 422。
- 当前模板使用静态属性 `show-alpha="false"`；Vue 编译后是字符串，Element Plus 会将其作为真值。
- Element Plus 在该情况下可能产生 `rgb(...)`，而后端仅接受六位十六进制颜色；其他播放设置的合法保存路径已存在。
- 无高影响待确认项；开发/测试需记录实际请求体、响应体及保存后的再次读取结果。

## 验收标准

以下 AC-001～AC-021 沿用 TASK-v2（其中 AC-001～AC-010 沿用 TASK-v1），不因本修复改变：

- AC-001：管理员只能读取和更新目标活动的弹幕配置；范围外数值或顶部/底部区域非法时返回 422。
- AC-002：同一活动重复读取得到同一当前 token；重新生成后 token 改变，旧 token 的 HTTP 和 WebSocket 请求均被拒绝。
- AC-003：有效 token 能读取会话并完成弹幕 WebSocket 首帧认证；无效 token 收到结构化错误后关闭。
- AC-004：用户发言后，聊天室保持既有完整消息事件；弹幕连接只收到消息 ID、活动 ID、正文和创建时间。
- AC-005：管理员保存配置后，已连接弹幕工具立刻收到并应用配置变更，无需重连。
- AC-006：桌面工具可粘贴 token、选择显示器并仅显示启动后的消息。
- AC-007：弹幕窗口透明、无边框、置顶、不可聚焦且鼠标穿透，底层窗口仍可操作。
- AC-008：轨道、字体、不透明度、速度、显示区域、颜色会影响渲染；消息队列有界且溢出时丢弃最旧项。
- AC-009：断线自动重连并以 `after_id` 补齐运行期间漏掉的新消息；活动关闭或结束后不产生新弹幕。
- AC-010：后端测试、全部 Vue 应用构建、Electron 类型/主进程构建以及 Windows NSIS 安装包构建通过。
- AC-011：管理员进入弹幕工具后，页面显示“真实弹幕测试”、当前状态以及开启/关闭按钮，状态与后端一致。
- AC-012：`open` 活动点击开启后，接口返回 `running: true`，页面显示运行中，并启动该活动的测试消息流。
- AC-013：已有聊天室和弹幕观察连接时，测试消息真实写入聊天记录；两条通道收到对应事件，消息 ID、活动 ID、正文一致，聊天室保留完整事件，弹幕保留四字段摘要。
- AC-014：至少产生两条消息时，至少有两个不同的 `sender_activity_user_id`，发送者名称均可识别为“弹幕测试用户”，正文可识别为测试消息。
- AC-015：同一活动重复运行测试时复用已有测试身份，不因重复开启创建同名重复身份。
- AC-016：同一活动重复开启保持成功且只有一条测试流；页面运行中禁用开启按钮。
- AC-017：运行中点击关闭返回 `running: false`，成功后不再产生新测试消息，既有消息可查询，重复关闭不报错。
- AC-018：`closed`/`ended` 活动开启请求返回 409 且不产生测试消息；运行中变为只读后最终停止，重新开启不自动恢复。
- AC-019：只开启一个活动的测试时，另一个活动保持关闭且没有测试消息；消息全部属于启动活动。
- AC-020：无有效超级管理员权限时，状态/开启/关闭请求被拒绝，不改变状态、不写入测试消息。
- AC-021：新增测试、受影响构建、模块文档和最终回归均有可复核证据，且不再将该功能描述为本地预览。

新增验收标准：

- AC-022：Given 管理员已打开目标活动且页面已加载满足既有约束的播放设置，When 不修改任何字段并点击“保存播放设置”，Then 对应 PUT 请求返回 HTTP 200，页面显示保存成功反馈，且不出现 422。
- AC-023：Given 管理员通过颜色选择器选择任意不透明颜色，When 播放设置有效且点击“保存播放设置”，Then PUT 请求中的 `text_color` 为 `#` 加六位十六进制字符，不得为 `rgb(...)`、`rgba(...)`、颜色名称或八位颜色值；接口返回 HTTP 200，回包及后续 GET 的颜色为同色的大写十六进制值。
