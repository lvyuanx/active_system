# TASK-v5：奖品支持上传图片

## 任务属性

- 等级：T6
- 状态：已冻结
- 输入版本：TASK-v1～v4 已交付能力及当前工作树
- 变更性质：跨管理端、后端、数据库、大屏的行为变更，涉及持久化字段/迁移、文件上传安全、活动隔离和运行时清理。
- 默认限制：图片可选；支持 JPEG、PNG、WebP；单文件最大 5 MiB；必须校验真实 MIME 与扩展名一致。
- 待确认项：无高影响待确认项。

## 目标与用户场景

为每个奖品增加可选图片能力。管理员可在奖品编辑行上传本地图片、预览、替换和移除；图片与
`activity_id + prize_id` 绑定并持久化；管理端重新读取可看到图片；公开抽奖大屏通过安全图片引用
显示奖品缩略图和中奖奖品图；历史无图奖品继续正常工作。

## 范围

- 管理端：抽奖奖品行图片选择、预览、替换、移除、失败提示和保存状态；同步 API 类型、表单 helper、页面样式。
- 后端：奖品图片字段/迁移、活动隔离的上传/访问/替换/删除接口，配置响应、公开快照和开奖事件的安全图片字段；
  必要的文件存储模块、配置和清理测试。
- 大屏：公开配置/快照/中奖事件中的可选图片引用、奖品列表和中奖奖品图片展示，缺图/加载失败回退文字。
- 文档和测试：同步模块 AGENTS、MEMORY/LEARNING/WIKI/README，并增加上传安全、权限、活动隔离、清理和回归证据。

## 非目标

- 不支持外部 URL、用户路径、绝对/相对路径或 base64 图片内容。
- 不接受 SVG、HTML、JavaScript、脚本、可执行文件或伪装成图片的文件。
- 不改变奖项结构、名称、数量、库存计算、抽奖资格、开奖幂等、中奖记录或既有 WebSocket 事件语义；仅添加可选图片字段。
- 不实现裁剪、编辑、滤镜、批量上传或素材库；删除/替换图片不删除奖品、奖项或中奖记录。

## 约束、安全与回滚

- 所有图片绑定和资源访问携带并校验 `activity_id`；仅超级管理员可上传、替换、移除和读取管理端图片。
- 公开图片引用不得暴露管理员 JWT、数据库路径、服务器绝对路径或内部存储目录。
- 后端同时校验文件大小、真实 MIME、扩展名一致性和可接受图片类型；失败不得写入绑定或留下不可追踪孤儿文件。
- 替换/删除清理旧文件；清理失败可记录并重试，不影响奖品库存/中奖记录。
- 历史数据库和无图奖品兼容，迁移可回滚；回滚只移除图片字段/接口/展示，不改变已有抽奖数据。

## 依赖

- `lottery_prizes` 及启动迁移机制、管理员 JWT/`require_superuser`、现有奖品配置 PUT、公开 WebSocket 快照和大屏组件。
- 部署环境的媒体目录、权限、备份和清理策略；前端 Element Plus 上传交互。

## 验收标准

### AC-501：管理员上传并预览

**Given** 管理员已登录并打开存在的奖品  
**When** 选择合法 JPEG、PNG 或 WebP  
**Then** 管理端显示预览，图片进入当前活动/奖品的待绑定状态，不影响其它字段。

### AC-502：保存后持久化

**Given** 奖品已选择图片  
**When** 保存配置并重新打开/刷新  
**Then** 图片仍绑定当前奖品并可预览，其他奖品和活动配置不受影响。

### AC-503：替换图片

**Given** 奖品已有图片  
**When** 选择另一张合法图片并保存  
**Then** 新图可见、旧图不可读取且旧文件清理，奖项/库存/中奖记录不变。

### AC-504：移除图片

**Given** 奖品已有图片  
**When** 移除图片并保存  
**Then** 图片字段为空，管理端和大屏按无图展示，旧资源不可访问且清理，奖品及中奖数据不变。

### AC-505：无图兼容

**Given** 历史或新奖品没有图片  
**When** 读取、保存、开奖或大屏连接  
**Then** 现有功能正常，不出现破图、异常字段或必须上传图片的阻断。

### AC-506：非法文件拒绝

**Given** 管理员上传文件  
**When** 文件为 SVG/HTML/脚本/可执行文件，或真实 MIME 与扩展名不一致  
**Then** 后端拒绝，不写绑定，不生成可公开访问文件。

### AC-507：超大文件拒绝

**Given** 管理员上传图片  
**When** 文件超过 5 MiB  
**Then** 后端拒绝，原图片绑定保持不变，不留下孤儿文件。

### AC-508：失败保持原状态

**Given** 奖品已有合法图片  
**When** 新图因格式、大小、读取或存储错误上传失败  
**Then** 原图和奖品名称/数量/库存/启用状态/中奖记录保持不变。

### AC-509：管理员权限

**Given** 请求无有效超级管理员凭证或使用活动用户凭证  
**When** 上传、替换、移除或读取管理端图片  
**Then** 请求被拒绝，不泄露图片、活动信息、路径或存储细节。

### AC-510：活动隔离

**Given** 图片属于活动 A 的奖品  
**When** 通过活动 B、错误奖品归属或篡改资源标识访问/替换/删除  
**Then** 请求被拒绝或返回不泄露存在性的安全错误，活动 A 不受影响。

### AC-511：公开大屏安全展示

**Given** 公开大屏接收现有抽奖快照或配置更新  
**When** 奖品存在图片  
**Then** 大屏收到活动隔离的安全引用，并显示奖品缩略图/中奖奖品图；不包含绝对路径、凭证或内部目录。

### AC-512：公开无图/加载失败回退

**Given** 奖品无图或图片加载失败  
**When** 大屏渲染奖品或中奖结果  
**Then** 保持文字、库存和中奖展示，不出现破图或阻断抽奖。

### AC-513：孤儿文件清理

**Given** 图片替换、移除、绑定失败或奖品合法删除  
**When** 后端完成业务操作和清理流程  
**Then** 无引用旧文件最终清理；失败可记录/重试，不影响业务数据且不泄露内部信息。

### AC-514：业务和协议回归

**Given** 管理员配置/开奖/重置，或大屏接收 `lottery.ready`、`config.updated`、`drawn`、`reset`  
**When** 图片功能启用或奖品无图  
**Then** 鉴权、事件、库存、幂等、名单、中奖历史、活动隔离和重置保持兼容，图片字段按权限安全暴露。
