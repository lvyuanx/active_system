# TASK-v5 主集成浏览器补充证据

## 环境

- 使用隔离临时后端 `http://127.0.0.1:8004`、管理端 `http://127.0.0.1:5189`、大屏 `http://127.0.0.1:5190`。
- 后端使用任务目录临时数据库 `browser-run.db` 和媒体目录 `browser-media`，管理员账号为本次测试专门生成的 `browser-admin`，未使用现有环境数据。
- 浏览器实际打开管理端 `/activities/aa5d844d-8326-408f-98e2-482a79d3f6c2/lottery` 和大屏 `/?activity_id=aa5d844d-8326-408f-98e2-482a79d3f6c2`。

## 管理端实际观察

1. 初始奖品行显示“选择图片”，且未保存奖品不可选文件。
2. 通过文件选择器选择仓库内合法 `apps/user-web/src/assets/active-logo.png` 后，DOM 出现 `img[alt="奖品图片预览"]` 和“待保存”状态。
3. 点击“保存抽奖配置”后收到“抽奖配置已保存并同步大屏”提示，页面仍保留奖品图片预览；修复前曾复现保存竞态导致图片消失，修复后替换流程 `previewCount=1`、`finalCount=1`。
4. 点击“移除图片”后保存，页面图片元素从 1 变为 0，文字、数量和抽奖控制仍在。
5. 选择 `README.md` 作为非法文件时，页面显示“仅支持 JPEG、PNG 或 WebP 图片”，未发起上传。
6. 管理端控制台 error/warn 日志为空。

## 大屏实际观察

1. 图片存在时，奖品板 DOM 有 `img.prize-image`，其 `src` 为活动隔离的 `/api/v1/activities/{activity_id}/lottery/prizes/{prize_id}/image?v={image_id}`，`naturalWidth=1254`，无控制台 error/warn。
2. 上传后删除媒体文件但保留数据库绑定，并广播配置更新后，图片请求 404；大屏 DOM 自动移除 `img.prize-image`，仍显示奖品名称“默认奖品”、库存 `1/1`、实时连接和等待抽奖文案。
3. 公开图片 URL 不含绝对路径、媒体目录、数据库路径、管理员凭证或原始文件名。

## 资源清理

- 临时服务仅用于本次测试，后台进程会在集成清理阶段停止；测试数据库和媒体目录位于任务目录临时范围，不影响项目运行数据。

## 广播修复后的实时同步复核

- 重启最新后端后，通过管理员媒体接口上传新 PNG，已连接大屏在不刷新页面的情况下出现新的 `img.prize-image`，`src` 使用新 `image_id`，图片 `naturalWidth` 正常。
- 通过管理员媒体接口删除图片，已连接大屏收到 `lottery.config.updated`，图片元素数量变为 0，奖品名称“默认奖品”、库存 `1/1` 和“实时连接”仍保留。
