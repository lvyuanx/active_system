# TASK-v4：奖项未保存即可添加奖品

任务等级：T4（单模块管理端操作逻辑优化，不改变后端接口和开奖协议）

## 目标

新增奖项后即可直接添加其子奖品，不要求用户先提交整个配置；保存时由前端自动完成临时奖项 ID 到真实奖项 ID 的转换。同时明确标注奖项排序字段，消除无标签数字造成的误解。

## 范围

- 新奖项使用前端临时 ID，奖品可以立即绑定到该奖项节点。
- 点击一次“保存抽奖配置”时，必要时先保存奖项，再自动保存奖品和规则。
- 将奖项数字字段标注为“排序”，并提示数值越小越靠前。
- 未保存奖品不进入开奖选择器；保留现有库存、删除和后端约束。

## 验收标准

- AC-401：新增奖项后“添加奖品”按钮立即可用，新增奖品显示在该奖项节点下。
- AC-402：保存包含新奖项和新奖品的配置后，奖品正确关联该奖项且无需用户执行第二次操作。
- AC-403：页面明确显示奖项字段为“排序”，并说明排序值含义；未保存奖品不生成空值开奖选项。
- AC-404：管理端类型检查、生产构建、后端回归和浏览器视觉验收通过。

## 风险与回滚

- 风险：双阶段 HTTP 保存在第二阶段失败时需要保留已取得的真实奖项 ID，确保用户可以重试；删除节点不能留下悬空奖品。
- 回滚：仅回退管理端表单 helper、视图和样式即可恢复原交互，不涉及数据库迁移。
