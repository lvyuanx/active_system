# TASK-v5：调整大屏活动名与奖品信息布局

任务级别：T4

## 目标

将活动名称移动到顶部 Header，并在原顶部标题区域展示当前奖品名称和已上传的奖品图片，减少信息重复并突出本轮奖品。

## 范围

- Header 居中显示当前活动名称。
- 顶部标题区域显示当前奖品名称和可选奖品图片；按进行中轮次、最近开奖结果、下一件可用奖品依次确定展示内容。
- 移除主抽奖面板内重复的奖品名称和中奖奖品图片，保留抽奖状态、球体和中奖者展示。
- 同步响应式样式、回归断言、模块文档和项目知识记录。

## 非目标

- 不改变开奖逻辑、WebSocket 协议、奖品上传/存储、库存计算或活动数据。
- 不改变球体停止、打散、中奖者中心放大和奖品进度板行为。
- 不触碰工作区中已有的代码变更或奖品媒体文件。

## 验收标准

### AC-001

Given 公开快照包含活动名称和当前可展示奖品。

When 大屏完成渲染。

Then 活动名称显示在顶部 Header，标题区域显示奖品名称；有图片时同时显示奖品图片。

### AC-002

Given 当前奖品没有图片，或图片加载失败。

When 大屏显示顶部奖品区域。

Then 奖品名称仍可见，不显示破损图片；其它抽奖内容不受影响。

### AC-003

Given 大屏处于桌面、移动端或短屏尺寸。

When 活动名和奖品信息完成分区布局。

Then Header、顶部奖品区和抽奖面板保持紧凑且不产生页面滚动，进行中和揭晓状态流程保持不变。
