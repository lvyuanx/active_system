# TASK-v3：抽奖进行中标签展示奖品图片

任务级别：T4

## 目标

当奖品配置了上传图片时，大屏抽奖进行中的顶部奖品标签显示对应奖品缩略图，同时保留奖项和奖品名称。

## 范围

- 从公开 `lottery.ready` 快照和配置更新后的奖项奖品数据中，按当前轮次的 `award_id`、`prize_id` 匹配图片。
- 在 `.round-prize-chip` 中展示可选奖品图片，并为图片加载失败提供文字回退。
- 补充桌面端、移动端样式、回归断言、模块文档和项目知识记录。

## 非目标

- 不修改开奖 WebSocket 协议、管理端上传流程、奖品图片存储或权限边界。
- 不改变抽奖球体、中奖者中心放大动画、奖项库存和开奖结果。
- 不触碰工作区中已有的奖品媒体文件删除或新增上传文件。

## 验收标准

### AC-001

Given 当前轮次正在抽奖，公开快照中存在与当前 `award_id`、`prize_id` 匹配的 `image_url`。

When 大屏渲染顶部奖品标签。

Then 标签显示对应奖品图片，并继续显示奖项和奖品文字。

### AC-002

Given 当前奖品没有图片，或图片请求加载失败。

When 大屏渲染或更新顶部奖品标签。

Then 不显示破损图片，原有奖项和奖品文字仍可见。

### AC-003

Given 大屏在桌面或移动端展示进行中轮次。

When 标签包含图片或图片回退到文字。

Then 标签保持紧凑布局，不造成页面横向或纵向滚动，且不改变现有开奖动画流程。
