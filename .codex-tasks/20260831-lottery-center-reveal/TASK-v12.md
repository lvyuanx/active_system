# TASK-v12：中奖用户名按奖品归属显示

任务级别：T4

## 目标

让奖品板中的中奖用户名显示在对应奖品下方，清晰表达每位中奖用户获得的具体奖品。

## 范围

- 按 `prize_id` 过滤奖项下的中奖记录。
- 将每个奖品及其中奖用户名包装为独立显示块，用户名显示在对应奖品行下方。
- 保留奖项中奖总数、奖品库存、图片和最近中奖人数量限制。
- 补充回归断言、样式、模块文档和项目知识记录。

## 非目标

- 不改变开奖逻辑、WebSocket、库存、奖品图片、用户头像或中奖结果数据。
- 不改变沉浸式抽奖、中奖者放大和页面恢复流程。
- 不触碰工作区中已有的代码变更或媒体文件。

## 验收标准

### AC-001

Given 一个奖项包含多个奖品和不同奖品的中奖记录。

When 大屏渲染奖品板。

Then 每位中奖用户名显示在其 `prize_id` 对应的奖品下方，不混入其它奖品。

### AC-002

Given 某个奖品没有中奖记录。

When 大屏渲染该奖品。

Then 只显示奖品信息，不显示空的用户名标签；其它奖品的中奖用户名不受影响。

### AC-003

Given 奖品板在桌面或移动端展示。

When 中奖用户名按奖品分组显示。

Then 布局保持紧凑、不产生页面滚动，库存、图片和奖项总数继续正常显示。
