# TASK-v9：移除当前奖品提示文字

任务级别：T4

## 目标

移除截图中标出的 `CURRENT PRIZE` 提示文字，让顶部区域只突出奖品图片和名称。

## 范围

- 删除顶部奖品区域的 `CURRENT PRIZE` 文案。
- 清理只服务于该文案的 `.kicker` 样式引用。
- 保留奖品图片、奖品名称、活动网页标题和抽奖区域状态。
- 补充回归断言、模块文档和项目知识记录。

## 非目标

- 不改变网页 `document.title`、活动名称来源、奖品图片、开奖逻辑或抽奖动画。
- 不改变奖品板、错误提示和响应式布局。
- 不触碰工作区中已有的代码变更或媒体文件。

## 验收标准

### AC-001

Given 顶部奖品区域显示奖品信息。

When 大屏加载完成。

Then `CURRENT PRIZE` 文字不再显示，奖品图片和名称仍可见。

### AC-002

Given 活动快照已加载。

When 浏览器读取页面标题。

Then 网页标题仍为活动名称，正文不因删除提示文字而改变活动状态信息。

### AC-003

Given 页面在目标大屏尺寸显示。

When 提示文字和对应样式被移除。

Then 页面不产生横向/纵向滚动，现有抽奖流程保持不变。
