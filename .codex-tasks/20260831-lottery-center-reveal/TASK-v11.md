# TASK-v11：中奖结果区域展示用户头像

任务级别：T4

## 目标

在抽奖结束恢复的中奖结果区域展示中奖用户头像，增强中奖结果的识别度。

## 范围

- 在正常中奖结果区域增加头像并与中奖用户名一起展示。
- 当前轮次优先使用参与者真实头像；历史结果或缺少参与者信息时使用稳定本地头像兜底。
- 抽奖沉浸式阶段继续只显示球体，中奖者中心放大层行为不变。
- 补充头像状态回归断言、样式、模块文档和项目知识记录。

## 非目标

- 不改变开奖 WebSocket 协议、中奖抽取、库存、球体动画或奖品图片。
- 不改变活动网页标题、奖品区域、奖项进度板和页面恢复流程。
- 不触碰工作区中已有的代码变更或奖品媒体文件。

## 验收标准

### AC-001

Given 抽奖结果已揭晓并恢复正常页面。

When 页面显示中奖用户。

Then 中奖区域同时显示用户头像和用户名。

### AC-002

Given 当前轮次包含中奖用户的头像 ID，或历史结果缺少头像 ID。

When 页面选择头像资源。

Then 当前轮次使用参与者头像，历史结果使用稳定本地头像，不请求外部图片。

### AC-003

Given 页面处于沉浸式抽奖或正常恢复状态。

When 头像加入中奖结果区域。

Then 沉浸式阶段不会提前显示中奖用户，恢复页面无横向/纵向滚动，既有中奖动画流程保持不变。
