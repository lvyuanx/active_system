# TASK-v4：收紧大屏顶部标题区

任务级别：T4

## 目标

缩小大屏顶部活动标题区的视觉占用，让抽奖面板更早进入视口并保留主要内容的展示空间。

## 范围

- 收紧大屏内容顶部留白、活动标题字号/行高和标题到抽奖面板的间距。
- 同步调整移动端和短屏覆盖值，保持标题、奖品标签和抽奖面板可见。
- 补充静态回归断言、模块文档和项目知识记录。

## 非目标

- 不改变活动名称、奖品标签、球体、中奖者放大动画或奖品板内容。
- 不改变开奖逻辑、WebSocket 协议、图片加载和活动数据。
- 不触碰工作区中已有代码变更或奖品媒体文件。

## 验收标准

### AC-001

Given 大屏在桌面尺寸显示活动标题。

When 页面完成渲染。

Then 标题区使用更小的字号、顶部留白和面板间距，活动名称仍清晰可读。

### AC-002

Given 大屏在移动端或短屏尺寸显示活动标题。

When 页面完成渲染。

Then 使用对应的紧凑覆盖值，不产生横向或纵向滚动，抽奖面板仍可使用。

### AC-003

Given 标题区尺寸被收紧。

When 抽奖处于进行中或中奖揭晓状态。

Then 球体、顶部奖品标签、中心中奖者放大层和奖品板的既有行为不变。
