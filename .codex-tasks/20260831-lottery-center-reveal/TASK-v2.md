# TASK-v2：移除最终中奖卡片

任务级别：T4

## 目标

移除大屏中奖揭晓结束时的矩形卡片，仅保留中奖用户从中心放大的头像与姓名，避免最后再次出现红框所标示的卡片容器。

## 范围

- `selecting` 阶段继续显示中心用户放大层。
- `revealed` 阶段复用同一中心用户层，保持头像和姓名可见。
- 删除最终卡片 DOM、背景、边框、阴影和对应动画。
- 更新测试断言、模块文档和任务证据。

## 非目标

- 不修改球体停止/打散/中奖逻辑、WebSocket 协议、开奖数据和管理端控制。
- 不移除中心用户本身、聚光效果、姓名或头像。
- 不改变奖品进度板和其他页面区域。

## 验收标准

### AC-001

Given 当前轮次已收到匹配的 `lottery.drawn` 并进入 `selecting`。

When 中奖用户从打散位置聚焦到舞台中心。

Then 中心用户放大层正常显示，并且不出现最终矩形卡片容器。

### AC-002

Given 聚焦动画完成并进入 `revealed`。

When 大屏保持最终中奖结果。

Then 头像和姓名继续留在中心，源码和渲染结果中不存在 `data-winner-card`/`.globe-winner` 卡片。

### AC-003

Given 大屏在桌面或移动端展示最终结果。

When 页面完成渲染。

Then 不产生横向/纵向滚动，`prefers-reduced-motion` 仍可快速完成中心放大层动画。
