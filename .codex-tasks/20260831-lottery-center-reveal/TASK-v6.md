# TASK-v6：放大奖品展示图片

任务级别：T4

## 目标

适当放大顶部当前奖品图片，让奖品信息在大屏上更醒目，同时保持标题区和抽奖面板不溢出。

## 范围

- 将顶部当前奖品图片调整为桌面端 64×64px、移动端 52×52px。
- 保留奖品名称、活动 Header 和现有图文布局。
- 补充回归断言、模块文档和项目知识记录。

## 非目标

- 不改变活动名称位置、奖品名称、开奖逻辑、WebSocket、球体或中奖动画。
- 不改变奖品图片来源、上传流程、失败回退和奖品板缩略图。
- 不触碰工作区中已有的代码变更或媒体文件。

## 验收标准

### AC-001

Given 顶部当前奖品存在可加载图片。

When 大屏渲染奖品信息。

Then 桌面端图片以 64×64px 显示，奖品名称仍可见。

### AC-002

Given 大屏处于移动端尺寸，或图片不存在/加载失败。

When 大屏渲染奖品信息。

Then 移动端使用 52×52px 图片规则；无图或失败时名称仍保留，不显示破损图片。

### AC-003

Given 奖品图片尺寸被放大。

When 页面在目标大屏尺寸完成渲染。

Then 标题区和页面不产生横向/纵向滚动，活动 Header、抽奖面板和现有动画行为保持不变。
