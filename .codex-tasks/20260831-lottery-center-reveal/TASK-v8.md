# TASK-v8：移除页面标题文字并设置网页标题

任务级别：T4

## 目标

移除截图中标出的 Header 活动名称和奖品下方提示语，将活动名称改为浏览器标签页标题。

## 范围

- 移除页面 Header 中可见的活动名称。
- 移除顶部奖品区域下方的默认提示语；保留真实错误提示和抽奖区域状态。
- 以活动快照名称动态设置 `document.title`，并提供“幸运抽奖”默认标题。
- 补充入口默认标题、回归断言、模块文档和项目知识记录。

## 非目标

- 不改变顶部奖品图片/名称、奖品板、球体、中奖者动画或开奖流程。
- 不改变活动数据、WebSocket 协议、奖品上传和图片失败回退。
- 不触碰工作区中已有的代码变更或媒体文件。

## 验收标准

### AC-001

Given 活动快照包含活动名称。

When 大屏加载完成。

Then 页面正文不再显示 Header 活动名称，浏览器标题显示该活动名称。

### AC-002

Given 顶部奖品区域显示奖品信息。

When 页面完成渲染。

Then 截图标出的默认提示语不再显示，奖品图片和名称仍可见，真实错误仍可反馈。

### AC-003

Given 页面在桌面或移动端显示。

When 两处文字被移除并设置网页标题。

Then 页面不产生横向/纵向滚动，现有抽奖流程和响应式布局保持不变。
