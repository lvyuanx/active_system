# TASK-v10：抽奖时沉浸式球体与揭晓后恢复

任务级别：T4

## 目标

开始抽奖时让大屏进入仅球体旋转的沉浸式画面；停止后展示中奖用户，揭晓完成后恢复正常奖品/奖项页面。

## 范围

- 活动轮次存在期间隐藏 Header、顶部奖品区、奖项进度板、底部信息和球体辅助文字，球体铺满大屏。
- 保留停止后的散开、中奖用户中心放大和最终揭晓动画。
- 最终揭晓停留约 2.2 秒后清理进行中轮次，恢复正常页面并保留最近中奖结果。
- 补充状态回归断言、响应式样式、模块文档和项目知识记录。

## 非目标

- 不改变开奖 WebSocket 协议、管理端开始/停止控制、中奖抽取和库存逻辑。
- 不改变奖品图片来源、活动网页标题、奖品板数据和中奖者动画本身。
- 不触碰工作区中已有的代码变更或媒体文件。

## 验收标准

### AC-001

Given 大屏收到 `lottery.draw.started` 并进入进行中轮次。

When 球体处于 rolling、scattering 或等待中奖者阶段。

Then 页面外围内容隐藏，球体占满可用视口并持续旋转/执行停止动画。

### AC-002

Given 停止后收到匹配的 `lottery.drawn`。

When 中奖者进入 selecting/revealed 阶段。

Then 中奖用户弹出并居中放大，揭晓期间不显示外围页面干扰内容。

### AC-003

Given 中奖者揭晓动画完成且没有下一轮排队。

When 恢复计时结束。

Then 大屏恢复正常 Header、当前奖品、奖项进度板和底部信息，并保留刚揭晓的中奖用户/奖品结果；桌面布局无滚动。
