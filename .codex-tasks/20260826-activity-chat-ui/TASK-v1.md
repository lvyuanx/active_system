## 目标与用户场景

- 输入区固定在聊天可视区域底部、底部导航上方，并兼容安全区。
- 输入框默认一行，随文本换行增长，最大三行。
- 消息超过一屏且用户位于底部阈值内时，新消息到达后自动滚到底部；用户阅读较早消息时不强制跳转。
- 在输入控件组正上方展示当前活动用户名和对应头像。

用户可以输入短消息或多行消息并保持输入区可见；停留在聊天底部时能看到实时新消息；向上阅读历史时不会被新消息打断；发送前可确认自己的用户名和头像。

## 范围

- 用户端活动聊天页的输入区布局、输入框高度行为、消息追加后的滚动行为和当前用户身份展示。
- 主要变更文件为 `apps/user-web/src/views/activity/chat.vue` 与 `apps/user-web/src/views/activity/activity.css`；现有 `index.vue`、`client.ts`、`ActivityAvatar.vue` 作为数据和组件依赖。
- 头像仅展示在输入区上方的当前用户身份区，不增加到聊天消息卡片。

## 非目标

- 不修改聊天消息结构、发送者字段、历史游标、分页或重连协议。
- 不修改 HTTP API、WebSocket 地址、认证方式、事件类型或消息 payload。
- 不新增后端接口、数据表、用户选择头像流程或头像资源。
- 不新增未读消息、回到底部按钮或聊天消息头像。

## 约束、风险与依赖

- 保持 Vue 3 + Vant 4 和现有活动页样式体系，保留消息长度、发送条件、活动状态和连接状态限制。
- 用户身份使用当前活动上下文中的 `user.username` 与 `user.avatar_id`；头像继续通过固定本地 SVG 映射展示。
- “最大三行”指输入控件的可视高度不超过三行，超过部分仍可编辑。
- 底部布局需兼容 Tabbar、安全区、移动端键盘和现有桌面 600px 预览限制。
- “靠近底部 1/3”按内容底部与当前视口底部的剩余距离不超过可视高度三分之一定义。
- 自动滚动触发点为实时新消息追加；加载更早消息不视为新消息。
- 风险包括键盘/安全区/Tabbar 遮挡、滚动阈值过宽打断阅读，以及新消息与历史加载并发时的位置抖动。
- 依赖现有活动壳传递已认证用户、`ActivityUserResponse.username/avatar_id` 字段和 `ActivityAvatar` 组件。

## 验收标准

### AC-001：输入区布局与自适应高度

**Given** 用户已进入活动聊天页，且消息列表可能需要滚动

**When** 页面首次渲染、用户输入文本并使文本分别达到一行、两行、三行及超过三行

**Then** 输入控件组保持在聊天可视区域底部、底部导航上方；输入框默认一行，随换行最多增长到三行，超过三行后高度不再增长且文本仍可编辑，发送按钮保持可用且无布局遮挡。

### AC-002：底部阈值内自动滚动

**Given** 消息列表内容高度超过可视高度，且用户当前距离内容底部不超过可视高度的三分之一

**When** 现有实时消息事件追加一条新消息

**Then** 新消息渲染完成后消息列表滚动到底部，最新消息可见。

**Given** 同样的消息列表条件，但用户距离内容底部超过可视高度的三分之一

**When** 追加新消息

**Then** 不强制滚到底部，用户当前阅读位置保持不被打断。

### AC-003：输入区当前用户身份

**Given** 当前活动用户对象包含 `username` 和 `avatar_id`

**When** 聊天页显示输入控件组

**Then** 在输入控件组正上方显示当前用户名和与 `avatar_id` 对应的本地头像；该身份区独立于聊天消息卡片，聊天消息内容、发送者字段及 WebSocket/API 协议保持不变。
