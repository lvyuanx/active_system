# TASK-v6：移除聊天输入框下方分隔线

## 状态

- 等级：T2
- 状态：已冻结
- 输入版本：TASK-v5、用户最新截图和明确反馈
- 待确认项：无

## 目标与范围

移除聊天输入框内部由 Vant `.van-cell::after` 生成的横向分隔线，让输入内容区域视觉连续；保留输入框自身边框、默认一行与按钮等高、1–3 行自适应、超三行内部滚动、底部 Tabbar 和已有聊天逻辑。

## 非目标

- 不移除输入框外框，不修改底部 Tabbar 的布局或其它列表分隔线。
- 不修改聊天 API、WebSocket、消息字段、头像映射、发送条件或滚动逻辑。
- 不恢复已经移除的聊天标题、连接状态和当前用户身份区域。

## 验收标准

### AC-001：输入框下方无内部横线

**Given** 用户进入聊天页

**When** 输入框为空或包含文本

**Then** 聊天输入 Field 不渲染 `.van-cell::after` 分隔线，输入区域视觉连续，同时保留输入框外边框。

### AC-002：既有输入布局保持

**Given** 用户输入一行、两行、三行及超过三行文本

**When** 输入框随内容增长

**Then** 默认一行仍与发送按钮等高，最多可视三行，超过三行仍可编辑且输入区仍位于 Tabbar 上方。

### AC-003：聊天行为不变

**Given** 用户浏览或发送聊天消息

**When** 页面渲染、实时追加或加载历史

**Then** 消息头像、用户名、气泡、条件滚动、历史锚点、父级导航、Tabbar 和聊天协议保持不变。
