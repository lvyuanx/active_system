# TASK-v7：移除登录后顶部 Header 并强化底部导航选中态

## 状态

- 等级：T2
- 状态：已冻结
- 输入版本：TASK-v6、用户最新明确要求
- 待确认项：无

## 目标

移除登录后活动壳的全局 `activity-nav`，让首页、聊天和“我的”页不再显示顶部 Header；
底部当前导航始终随路由同步，并同时通过金色图标、金色文字、加粗文字和可见包裹背景明确高亮。

## 用户场景

- 活动用户登录后直接进入首页，不再看到占用垂直空间的全局顶部 Header。
- 用户直接访问、刷新、点击导航或使用浏览器前进后退时，底部仅高亮当前路由对应入口。
- 刘海屏和带底部手势区域的设备仍能安全显示主体、输入框和 Tabbar。

## 范围

- 移除登录后首页、聊天和“我的”页共用的 `VanNavBar` 及其专属样式和导入。
- 保留认证页语义化 `login-hero`，不改变其活动标识、上下文和登录信息流。
- 由 `route.path` 持续派生 Tabbar 数值，并使用适配 Vant `route` 模式的命名路由目标。
- 为当前 Tabbar 项增加金色图标、金色文字、加粗文字和可见背景/边框包裹。
- 将登录后顶部 safe-area 移到活动壳，并按移除 Header 后的可用高度调整首页、聊天和“我的”页。
- 保留 Tabbar 底部 safe-area，确保聊天输入区位于 Tabbar 上方。

## 非目标

- 不删除或改写认证页 `login-hero`。
- 不修改首页、聊天、“我的”三个入口的名称、顺序或路由目标。
- 不重构业务页，不修改活动 API、Token 隔离、聊天协议、头像映射或用户既有改动。
- 不改变聊天历史锚点、条件滚动、断线重连、消息发送和输入框既有行为。

## 实现约束

- 优先修改 `apps/user-web/src/views/activity/index.vue`、`activity.css` 和 `chat.css`。
- 只有验证证明必要时才修改 `apps/user-web/src/router/index.ts`；本任务不得引入新依赖。
- 顶部 safe-area 由登录后活动壳承接，不得复用或改变认证页语义 Header。
- Tabbar 选中态不能仅用颜色区分，必须提供可见背景或包裹形态。
- 不启动长期服务；开发阶段使用类型检查、生产构建和静态检查提供基础验证。

## 风险

- Vant `route` 模式按路由记录匹配目标；动态实路径与包含参数占位符的路由记录可能不相等。
- 移除 52px Header 后若未同步调整高度，聊天区会残留空白或输入框与 Tabbar 重叠。
- safe-area 若同时作用于 Tabbar 根节点和导航项，可能重复占用底部空间。

## 验收标准

### AC-001：登录后无顶部 Header

**Given** 活动用户已登录并进入首页、聊天或“我的”页

**When** 页面完成渲染

**Then** 三个页面均不显示 `activity-nav` 或其它全局顶部 Header，且顶部无旧占位空白。

### AC-002：认证页 Header 保留

**Given** 当前活动用户未登录

**When** 活动认证页完成渲染

**Then** 语义化 `login-hero`、活动标识、活动上下文和登录标题正常显示。

### AC-003：直接访问和刷新时选中态正确

**Given** 用户拥有有效活动会话

**When** 直接访问或刷新首页、`/chat`、`/me`

**Then** 仅对应的首页、聊天或“我的”导航项处于选中状态。

### AC-004：导航切换与历史路由同步

**Given** 用户位于任一登录后活动页面

**When** 点击底部导航或使用浏览器前进后退

**Then** 路由目标和唯一选中态持续同步。

### AC-005：选中态视觉明显

**Given** 任一底部导航项为当前项

**When** 用户查看底部 Tabbar

**Then** 当前项同时呈现金色图标、金色文字、加粗文字和可见背景/包裹形态，未选中项中性弱化。

### AC-006：安全区与布局无重叠

**Given** 页面运行于普通屏幕或具有顶部/底部 safe-area 的移动设备

**When** 首页、聊天或“我的”页完成布局

**Then** 顶部和底部安全区保留，主体与 Tabbar 不重叠，页面不残留旧 Header 高度。

### AC-007：聊天区利用新增高度

**Given** 用户进入聊天页并输入一至多行消息

**When** Header 已移除且输入框自适应高度

**Then** 消息区利用新增高度；输入框默认一行与按钮等高、最多三行、超出内部滚动且位于 Tabbar 上方。

### AC-008：既有业务行为保持

**Given** 用户登录、浏览历史消息、接收实时消息或发送消息

**When** 本次活动壳和导航样式变更生效

**Then** API、Token、聊天协议、头像、历史锚点、条件滚动、重连和发送行为保持不变。
