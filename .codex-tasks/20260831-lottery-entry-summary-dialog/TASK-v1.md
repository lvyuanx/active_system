# TASK-v1：抽奖名单摘要移入特殊配置弹窗

任务级别：T4

## 目标

管理端实时抽奖配置主页面不展示抽奖名单人数、可抽奖人数、黑名单、白名单、已停用统计和规则说明；这些信息统一放入“特殊配置”弹窗中展示。

## 范围

- 主页面“抽奖名单”区域仅保留标题和“特殊配置”入口。
- 弹窗内展示名单统计摘要和抽奖资格规则说明。
- 保留现有安全码验证、名单搜索/筛选/分页和黑白名单即时更新。
- 同步管理端 lottery 模块说明、项目进度/知识和任务证据。

## 非目标

- 不改变后端名单摘要接口、抽奖资格计算和安全码校验。
- 不改变“特殊配置”按钮文案、弹窗打开权限或名单操作行为。
- 不修改大屏、用户端和其他管理端页面。

## 验收标准

### AC-001

Given 管理员打开实时抽奖配置页。

When 页面展示“抽奖名单”区域。

Then 主页面不显示参与者总数、可抽奖/黑名单/白名单/已停用统计和名单规则说明，仅显示标题与“特殊配置”入口。

### AC-002

Given 管理员通过安全码验证打开“特殊配置”弹窗。

When 弹窗加载名单。

Then 弹窗展示上述统计和规则说明，且摘要随现有名单更新事件保持同步。

### AC-003

Given 管理员在弹窗内使用搜索、筛选、分页或切换黑白名单。

When 执行现有名单操作。

Then 原有名单加载、保存和关闭行为不受影响。

### AC-004

Given 本次页面和文档改动完成。

When 执行管理端类型检查、生产构建和差异检查。

Then 验证通过且不包含越界文件改动。
