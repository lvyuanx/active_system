输入版本：`TASK-v1`；本地 Vite `http://localhost:5174/?activity_id=demo`

页面无活动数据时使用“等待奖品/暂无奖项配置”状态验证容器结构；该状态不影响布局方向判断。

补充检查：

- 1:1 方屏同时满足 CSS 的 `min/max-aspect-ratio: 1 / 1`，最终由方屏覆盖规则保持左右布局；1000×1001 仅满足 `max-aspect-ratio: 1 / 1`，最终使用上下布局。
- 竖屏奖项板 `position` 为 `static`、`overflow-y` 为 `auto`，不会覆盖主抽奖区。
- `document.documentElement.scrollWidth/scrollHeight` 与视口宽高一致；`body` 同样没有超出视口。
