# TASK-v2：管理端真实聊天室弹幕测试

## 目标

在活动管理端的“弹幕工具”页面增加真实弹幕测试开关。管理员开启后，后端使用多个明确标记的测试活动用户，
沿用现有聊天室消息持久化和广播链路发言，让聊天室与弹幕投屏器都能看到设置效果；关闭后停止继续发送。

本版本保留 `TASK-v1` 的 AC-001 至 AC-010，新增 AC-011 至 AC-021。`TASK-v1` 的桌面工具、token、弹幕摘要、
多显示器和渲染要求不因本版本改变。

## 用户场景

1. 超级管理员进入活动弹幕工具，查看真实测试的当前状态。
2. 活动处于“进行中”时点击开启，聊天室出现来自多个“弹幕测试用户”的消息，弹幕投屏器同步显示正文。
3. 管理员调整弹幕设置时，已连接投屏器继续实时应用设置，测试消息仍走同一弹幕通道。
4. 管理员点击关闭后停止新消息，已经写入的消息保留在聊天室和历史记录中。
5. 活动关闭或结束时不能启动测试，运行中的测试在下一次写入检查时停止；重新开启活动不会自动恢复。

## 范围

- 管理端弹幕页面增加测试状态、开启按钮、关闭按钮和明确的真实聊天室说明。
- 增加按 `activity_id` 隔离的管理员状态查询、开启和关闭接口。
- 为每个活动准备并复用多个测试活动用户；基线为 6 个用户，名称带“弹幕测试用户”标识。
- 测试消息写入 `activity_chat_messages`，并同时广播标准聊天室事件和弹幕正文摘要。
- 增加端到端后端测试和受影响模块文档。

## 非目标

- 不实现本地假预览或仅在浏览器中生成的模拟消息。
- 不修改用户端聊天界面、既有聊天室协议或弹幕摘要字段。
- 不把用户名加入弹幕投屏器消息，不提供测试用户数量、频率或文案的管理端配置。
- 不删除测试用户或清理已经写入的测试消息。
- 不实现多副本之间的测试任务协调；不修改桌面弹幕窗口和渲染能力。

## 约束、风险与依赖

- 所有读写必须携带目标 `activity_id`；只有超级管理员可操作测试接口。
- 只有 `open` 活动可开启测试；`closed`/`ended` 活动返回 409 且不写入消息。
- 至少使用两个不同的稳定 `activity_user_id`；测试用户必须能从聊天室完整消息的 `sender_username` 识别。
- 测试消息是真实演示数据，会保留在聊天历史；页面和文档必须明确这一点，避免与普通用户发言混淆。
- 同一活动不能创建并行测试流；开启和关闭请求应幂等。
- 依赖活动生命周期、超级管理员认证、聊天 service/manager、弹幕 manager/历史接口和管理端请求封装。
- 主要风险是运营数据噪声、活动状态切换时序和单进程任务状态限制；不在本版本扩展部署架构。

## 待确认项

无高影响待确认项。若未来需要清理测试数据、配置测试参数或支持多副本协调，必须新建任务版本。

## 验收标准

- AC-001 至 AC-010：沿用 `.codex-tasks/20260827-danmaku-desktop/TASK-v1.md`，覆盖原弹幕配置、token、WebSocket、
  桌面窗口、渲染队列、断线补齐和构建交付要求。
- AC-011：管理员进入弹幕工具后，页面显示“真实弹幕测试”、当前状态以及开启/关闭按钮，状态与后端一致。
- AC-012：`open` 活动点击开启后，接口返回 `running: true`，页面显示运行中，并启动该活动的测试消息流。
- AC-013：已有聊天室和弹幕观察连接时，测试消息真实写入聊天记录；两条通道收到对应事件，消息 ID、活动 ID、
  正文一致，聊天室保留完整事件，弹幕保留四字段摘要。
- AC-014：至少产生两条消息时，至少有两个不同的 `sender_activity_user_id`，发送者名称均可识别为“弹幕测试用户”，
  正文可识别为测试消息。
- AC-015：同一活动重复运行测试时复用已有测试身份，不因重复开启创建同名重复身份。
- AC-016：同一活动重复开启保持成功且只有一条测试流；页面运行中禁用开启按钮。
- AC-017：运行中点击关闭返回 `running: false`，成功后不再产生新测试消息，既有消息可查询，重复关闭不报错。
- AC-018：`closed`/`ended` 活动开启请求返回 409 且不产生测试消息；运行中变为只读后最终停止，重新开启不自动恢复。
- AC-019：只开启一个活动的测试时，另一个活动保持关闭且没有测试消息；消息全部属于启动活动。
- AC-020：无有效超级管理员权限时，状态/开启/关闭请求被拒绝，不改变状态、不写入测试消息。
- AC-021：新增测试、受影响构建、模块文档和最终回归均有可复核证据，且不再将该功能描述为本地预览。
